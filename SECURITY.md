# Security

## Reporting a concern

Please report security concerns privately, not in public issues or pull requests.

Use GitHub's private reporting form on this repository: open the **Security** tab and choose the private report option. Include what you found, how to reproduce it, and what it affects. You will get an acknowledgement, and fixes are coordinated privately before any public note.

## Supported versions

Circletube is pre-release. Only the `main` branch is maintained.
